# Portfolio OS icon artwork

Each launcher uses a locally bundled image in `apps/`. The same image appears on the desktop, in Start, on the phone and in window titles. Nimbus uses Chrome’s recognizable browser artwork. App names identify the portfolio experiences that open.

- [Browser, publishing and productivity icon sources](brand-sources.md)
- [Desktop utilities, games and folder icon sources](desktop-sources.md)

The renderer preserves transparent backgrounds and the artwork’s original colors. It uses a Lucide glyph when an image fails to load. The containing launcher supplies the accessible name.

The earlier monochrome assets in `lucide/` came from [Lucide 0.454.0](https://github.com/lucide-icons/lucide/tree/dcd19cedc9fe69a6c6da30c65f412e2dbea585f7/icons). Their [Lucide](LICENSE-lucide) and [Feather](LICENSE-feather) notices are included here.
